# aic-dc-decks

Public, unlisted home of the AIC-DC working-session decks: **https://decks.aic-dc.net/**.
Served by GitHub Pages from the root of `main`. Built in the estate by `DC-Decks/build.py`;
nothing here is edited by hand.

Publish a rebuilt site (on Em's word only): `./publish.sh` (or `./publish.sh --dry-run` first).
Addresses (`/session-<n>`) are printed in QR codes and are never renamed or removed;
`publish.sh` refuses to run if one would disappear.
